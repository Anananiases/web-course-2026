# Лаба 7. Лента постов с бесконечным скроллом

Подгружает посты с jsonplaceholder.typicode.com по 10 штук при прокрутке страницы.
Поиск по заголовку фильтрует уже загруженные данные на клиенте (дебаунс 300 мс),
без повторных запросов на сервер. Есть лоадер, сообщение «Больше постов нет»
и обработка сетевых ошибок.

## Запуск
Открыть `index.html` в браузере (или запустить `python -m http.server` из папки task7).
Нужен интернет — данные тянутся с публичного API.
