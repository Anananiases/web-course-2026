# Simon Says

Лабораторная №5. Игра «Симон говорит».

## Как играть
1. Нажмите «Старт».
2. Смотрите, какие секторы подсвечиваются.
3. Повторите последовательность кликами.
4. Каждый успешный раунд последовательность удлиняется на 1.
5. Ошибка — конец игры. Нажмите «Старт», чтобы сыграть заново.

## Технические решения
- Состояние игры хранится в объекте `game` (sequence, playerIndex, phase, timers).
- Показ последовательности — `async/await` над `setTimeout` (через Promise).
- Все таймеры запоминаются в `game.timers` и отменяются через `clearAllTimers()`.
- Клики вне фазы `'input'` игнорируются.
- Звук — Web Audio API (осциллятор), без внешних файлов.
